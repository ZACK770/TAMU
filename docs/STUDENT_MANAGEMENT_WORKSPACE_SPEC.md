# תכנית וורקספייס לניהול תלמידים

## סקירה כללית
ורקספייס לניהול תלמידים יאפשר למנהל לצפות, לערוך ולנהל את כל המידע הקשור לתלמידים במערכת.

## מודל נתונים (מהסכמה הקיימת)

### User
- `id` - מזהה ייחודי
- `phone` - מספר טלפון (ייחודי)
- `fullName` - שם מלא
- `totalPoints` - סה"כ נקודות שהרוויח
- `availablePoints` - נקודות זמינות למימוש
- `createdAt` - תאריך הרשמה
- `updatedAt` - תאריך עדכון אחרון

### קשרים
- `examSessions` - היסטוריית מבחנים
- `redemptions` - היסטוריית מימושים

## רכיבי הוורקספייס

### 1. עמוד רשימת תלמידים (StudentsListPage)

#### טבלת תלמידים עם DataTable
עמודות:
- **שם מלא** - `fullName` (מיון, חיפוש)
- **טלפון** - `phone` (מיון, חיפוש)
- **נקודות זמינות** - `availablePoints` (מיון)
- **סה"כ נקודות** - `totalPoints` (מיון)
- **תאריך הרשמה** - `createdAt` (מיון)
- **מספר מבחנים** - ספירת `examSessions` (מיון)
- **מספר מימושים** - ספירת `redemptions` (מיון)
- **סטטוס** - פעיל/חסום (אם נוסיף שדה זה)
- **פעולות** - כפתור צפייה בפרופיל, כפתור עריכה

#### פילטרים
- חיפוש טקסטואלי (שם, טלפון)
- פילטר לפי טווח נקודות זמינות
- פילטר לפי סטטוס (פעיל/חסום)
- פילטר לפי טווח תאריכי הרשמה

#### פעולות גלובליות
- כפתור "ייצוא רשימת תלמידים" (CSV/Excel)
- כפתור "הוספת תלמיד ידנית" (אם נרצה לאפשר זאת)

### 2. עמוד פרופיל תלמיד (StudentProfilePage)

#### כותרת
- שם מלא
- מספר טלפון
- תאריך הרשמה
- כפתור "חזור לרשימה"

#### סטטיסטיקות ראשיות (כרטיסים)
- נקודות זמינות
- סה"כ נקודות
- מספר מבחנים שבוצעו
- ציון ממוצע
- מספר מימושים
- נקודות שמומשו

#### טאבים

**טאב 1: פרטים אישיים**
- טופס עריכה:
  - שם מלא (עריכה)
  - מספר טלפון (עריכה - עם אימות)
  - סטטוס (פעיל/חסום) - אם נוסיף שדה זה
  - הערות מנהל (שדה טקסט חופשי להערות פנימיות)
- כפתור "שמור שינויים"

**טאב 2: היסטוריית מבחנים**
- DataTable עם כל המבחנים של התלמיד:
  - כותרת מבחן
  - ציון
  - נקודות שהרוויח
  - תאריך התחלה
  - תאריך סיום
  - זמן שבילה
  - סטטוס (הושלם/בתהליך)
  - פעולות (צפייה בפירוט מבחן)
- פילטרים: סטטוס, טווח תאריכים, טווח ציונים

**טאב 3: היסטוריית מימושים**
- DataTable עם כל המימושים של התלמיד:
  - שם הטבה
  - נקודות שמומשו
  - תאריך מימוש
  - סטטוס (בהמתנה/אושר/נדחה/הושלם)
  - הערות
  - תאריך עיבוד
  - מי אישר/דחה
- פילטרים: סטטוס, טווח תאריכים

**טאב 4: ניהול נקודות**
- טבלת היסטוריית שינויי נקודות (אם נוסיף טבלה כזו):
  - סוג שינוי (הוספה/הפחתה/מימוש/החזרה)
  - כמות
  - סיבה
  - תאריך
  - מי ביצע
- טופס הוספת/הפחתת נקודות ידנית:
  - סוג פעולה (הוספה/הפחתה)
  - כמות
  - סיבה (חובה)
  - כפתור "בצע"

**טאב 5: הגדרות מתקדמות**
- אפשרויות נוספות:
  - חסימת תלמיד (למנוע כניסה למערכת)
  - איפוס סיסמה/קוד אימות
  - שליחת הודעה SMS ידנית
  - מחיקת תלמיד (עם אזהרה ואישור כפול)

## שינויים נדרשים בסכמת הנתונים

### הוספות מוצעות למודל User
```prisma
model User {
  id              String           @id @default(uuid())
  phone           String           @unique
  fullName        String?
  totalPoints     Int              @default(0)
  availablePoints Int              @default(0)
  isActive        Boolean          @default(true)  // חדש
  adminNotes      String?          // חדש - הערות מנהל
  blockedAt       DateTime?        // חדש - תאריך חסימה
  blockedBy       String?          // חדש - מי חסם
  createdAt       DateTime         @default(now())
  updatedAt       DateTime         @default(now()) @updatedAt
  examSessions    ExamSession[]
  redemptions     UserRedemption[]
  pointHistory    PointHistory[]   // חדש - היסטוריית נקודות
}
```

### טבלה חדשה להיסטוריית נקודות
```prisma
model PointHistory {
  id          String   @id @default(uuid())
  userId      String
  user        User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  type        String   // 'earned', 'redeemed', 'manual_add', 'manual_subtract', 'refund'
  amount      Int
  reason      String?
  description String?
  createdAt   DateTime @default(now())
  createdBy   String?  // מי ביצע את השינוי (אם ידני)

  @@index([userId])
  @@index([createdAt])
}
```

## API Endpoints נדרשים

### רשימת תלמידים
- `GET /api/admin/students` - רשימת כל התלמידים עם פג'ינציה ופילטרים
- `GET /api/admin/students/:id` - פרטי תלמיד בודד
- `PUT /api/admin/students/:id` - עדכון פרטי תלמיד
- `DELETE /api/admin/students/:id` - מחיקת תלמיד
- `POST /api/admin/students/:id/block` - חסימת תלמיד
- `POST /api/admin/students/:id/unblock` - ביטול חסימה
- `GET /api/admin/students/:id/exams` - היסטוריית מבחנים
- `GET /api/admin/students/:id/redemptions` - היסטוריית מימושים
- `GET /api/admin/students/:id/points` - היסטוריית נקודות
- `POST /api/admin/students/:id/points` - הוספה/הפחתת נקודות ידנית
- `GET /api/admin/students/export` - ייצוא רשימה ל-CSV/Excel

## שיקולים נוספים

### אבטחה
- רק מנהלים מאומתים יכולים לגשת לוורקספייס זה
- לוג של כל הפעולות המנהליות (מי עשה מה ומתי)

### UX
- אישור כפול לפעולות משמעותיות (מחיקה, חסימה, שינוי נקודות)
- הודעות הצלחה/כישלון ברורות
- אפשרות לביטול פעולות (Undo) עבור שינויי נקודות ידניים

### פיצ'רים עתידיים אפשריים
- דוחות מסכמים על תלמידים
- השוואה בין תלמידים
- יצירת קבוצות תלמידים
- שליחת הודעות בודקות לקבוצות
- גרפים ותרשימים של התקדמות
